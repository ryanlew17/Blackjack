# 主动技目录与资格

@req REQ-2026-027

catalog.ts登记15技稳定ID、双语键、公开／隐身与发动窗口、五档场次数；availableSkillIds要求显式可玩难度，次数为0或难度不可玩时不可选。不新增购买货币、技能存档或独立解锁进度，不混入道具图鉴ID。

目录资格与执行准入分离：engine/skills.ts当前准入全部15技，round.skills在消耗随机前校验并冻结双方选择，该档0次、未解锁或缺少必要依赖的配置仍被拒绝。次数、Game许可、发动状态、私有观察与清理属于同一竞赛引擎；激发的监控／点数待办及夺心魄的受控Turn复用相同Turn起始排序、普通Hit／Stay和唯一结算链，私有排序不投影；魂迁通过同一PlayTrump完成一次拦截与效果规划，成功时才按容量生成悔牌，技能奖励不冒充可撤销卡体差量。双生花仅在作用于对方Turn的明确反应边界秘密布置，通用放行后原方继续；下一本人Turn按共同待办顺序取快照，以新实例替换明牌／道具手牌，保留自己的原暗牌首位并去除旧绑定。反应、私有次数、复制知识和生命周期复用相同观察；不复制来源豁免。应用负责提交／回放，页面不直接操作权威状态。

破万法的公共封锁覆盖施放Round及后两个Round，对方禁用独立持续到Game结束；无视隐身取消全部待生效效果，生生不息豁免。首个公开帧同步施放方effectActive与对方disabled，生生不息不锁定；秘密取消只给技能本人，不补公开布置或次数历史。生生不息免疫这些限制，按共同Turn起始顺序等概率生成冻结本档的可用道具定义，直接生成牌的来源标签随转移保留、复制不继承；持续状态在Game结束清除。技能实际成功历史跨Game保留，回仙只依据本人canRecover恢复1次及本Game额外许可，不清除禁用或自动发动；恢复差量复用道具悔牌机制。

selection.ts在确认时从同一可用集合按等长区间均匀选AI一次，不依玩家所选改变集合或排除同技能；无效／0次／锁定选择在采样前拒绝，返回冻结的双方SkillRules。选择随机由应用注入，与技能效果及数字／资源流分开；预览／取消不调用此函数。

完整规则与待实现边界见[竞赛规则](../../../../docs/design/contest-rules.md#12-主动技战前选择与牌桌)；验收证据留在REQ-027。
