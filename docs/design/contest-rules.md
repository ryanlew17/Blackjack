# design/contest-rules — 竞赛模式设计基线（S0，未实现）

## 1. 术语与层级

| 层级 | 中文   | 英文  | 规则                                                                                         |
| ---- | ------ | ----- | -------------------------------------------------------------------------------------------- |
| 场   | 大比分 | Match | 竞赛单位：BO-N，按难度 BO3/BO5/BO7/BO9，先赢多数"局"获胜——即整场的"通关 / 胜利"              |
| 局   | 小比分 | Game  | 场的计分单位：所有难度统一**先得 5 分**；平分递延目标（4:4→7、6:6→9…），胜局得大比分 +1      |
| 回合 | 回合   | Round | 局的计分单位：一回合 21 点对弈——双方停牌后更接近 21 点、或天然 Blackjack 的一方获得小比分 +1 |

模式英文名 **Contest Mode**（英文界面与文档使用）。

## 2. 赛制与计分

- 难度 → 场赛制：轻松 BO3（先赢 2 局）、标准与挑战 BO5（3 局）、危险 BO7（4 局）、噩梦 BO9（5 局）；BO-N 即最多打 N 局、先赢多数（过半）局者胜（如 BO5 的 3:0 / 3:1 / 3:2）。
- 局内计分（**目标递延制**）：目标分初始为 5，先到达当前目标分者胜该局；当双方**同分到达"当前目标分 − 1"**（4:4、6:6、8:8…）时目标分 +2（7、9、11…）。逐分（+1）推进时递延先于一分分差胜利触发，故各档最小胜利比分为 5:3、7:5、9:7…；但**加倍卡的 +2 跳分可越过分平点直接到线**（如 3:4→5:4），一分分差胜利仍可出现。
- 回合计分：赢家获得小比分 +1、输家使对方 +1；**加倍卡**使本回合积分变化 ×2（赢 +2 / 输对方 +2）。平局（push）双方不计分，该回合作废继续（作废回合仍计入坐庄轮换次序）；天然 Blackjack 按普通 +1 胜计（竞赛无赔率概念）。
- 局结束（小比分定出胜负、大比分 +1 后）：**清空双方道具手牌并重建牌靴**，相当于重新游戏；坐庄权按轮换次序延续，不重新抛硬币。
- 场结束：先赢多数局者获胜（BO-N 过半，场内无平局）——即整场比赛的"通关 / 胜利"，是难度解锁链的完成判定（见 §5）。

## 3. 坐庄与 AI

- 开局**抛硬币**决定先庄，此后逐回合轮换。
- 庄家方自动按 S17 补牌——坐庄回合是"喘息回合"，也是打出道具手牌卡的时机；AI 坐庄与玩家坐庄遵循同一庄家规则。
- AI 闲家要牌：可见信息最优——基本策略并计入已见牌，不透视未发的牌。
- AI 道具使用：固定强启发式。**AI 始终以最优决策应战，不随难度变化**——"最优"落地为上一条的可见信息要牌与本条的启发式；难度只约束玩家侧的道具能力（见 §5）。

## 4. 道具卡与牌靴

### 4.1 抽取与使用语义

- 道具卡**计入 hit**：一次要牌可能抽到扑克或道具卡，抽到任意一种后该方均可随时停牌——"下一张是道具还是爆牌"的不确定性是核心张力。
- 抽到**即效卡**立即结算；抽到**手牌卡**加入道具手牌区，可在自己回合打出或弃牌（每回合打出限 1 张）。
- 每回合道具抽取上限为每人 2 张；道具手牌容量上限随难度提高（1/2/2/3/3，见 §5）。

### 4.2 牌靴构成与权重公式

- 牌靴 = 52 张扑克 + 每种道具卡固定张数**全量入靴**；在**局开始时构建、局内跨回合持续**（消耗性属性因此有意义）。
- 扑克用毕入弃牌堆；**牌靴内扑克剩余为 0 时立即重洗弃牌扑克入靴**。道具卡不设弃牌堆——回收型始终在靴内，消耗型离场即本局出局——因此扑克侧在局内永不为空，权重公式不会出现两侧同为 0 的退化。
- 权重公式（保证扩卡后概率不漂移）：设难度目标道具概率 p（初值见 §5）。**适用前提**：道具侧尚有剩余张数，且该玩家未达本回合道具抽取上限（§4.1）。前提满足时，任意一次抽取——
  - 扑克侧总权重 = 剩余扑克张数；
  - 道具侧总权重 = p/(1−p) × 剩余扑克张数；
  - 道具侧内部按各卡剩余张数占比分摊。
- **边界退化**（不强行维持 p）：道具侧剩余为 0（本局消耗型全部离场）→ 道具侧权重按 0 计，后续必抽扑克——消耗性设计的自然结果；该玩家已达本回合抽取上限 → 该玩家道具侧权重按 0 计，本回合剩余要牌只出扑克。
- 推论（在适用前提下）：卡池扩容（后续版本加卡）、牌靴消耗、双牌组卡翻倍扑克基数，均不改变 P(道具)≈p；双牌组卡的价值在于牌张分布变化（成分变化更慢、计数更难）。

### 4.3 消耗性（卡牌固有属性）

每张道具卡自带"**用后是否回到牌堆**"属性：回收型用后立即洗回牌靴、可再次抽到；消耗型本局内不再出现。局结束重建牌靴时恢复全部初始张数。

### 4.4 卡池与迁移卡

- 类别（随 S2 定稿具体清单）：积分增益、战斗增益、中立、难度变化、整蛊等。
- 已定迁移卡：
  - **加倍卡**：本回合积分变化 ×2（赢 +2 / 输对方 +2）；
  - **保险卡**：对手天然 Blackjack 时本回合视为平局；
  - **双牌组卡**：当前局内向牌靴追加第二副扑克；局结束重建时恢复一副。
- 竞赛模式**无分牌、无投降**。
- 卡片效果须表达为**有限效果原语**的组合（modifyCardValue / peek / forceDraw / discardCard / reshuffle / swapCard / ruleToggle / revealHand / doubleStakes / naturalGuard …，S2 定稿）；卡牌目录（id、类别、效果原语、即效或手牌、张数、消耗性）定义于 domain，名称与描述只存 i18n 双语字典——domain 不含用户可见字符串。

## 5. 难度与解锁链

| 难度 | 场赛制 | 道具概率 p（初值） | 道具手牌容量上限（初值） | 卡池        |
| ---- | ------ | ------------------ | ------------------------ | ----------- |
| 轻松 | BO3    | 10%                | 1                        | 基础池      |
| 标准 | BO5    | 14%                | 2                        | 基础池      |
| 挑战 | BO5    | 16%                | 2                        | 基础 + 进阶 |
| 危险 | BO7    | 18%                | 3                        | 基础 + 进阶 |
| 噩梦 | BO9    | 22%                | 3                        | 全量        |

- 数值均为初值，S3 调参；难度只约束道具与赛制，**不改 AI**。
- 解锁链：轻松 → 标准 → 挑战 → 危险 → 噩梦 → 自定义对局；赢下该难度一场比赛视为完成，失败可无限重试。
- 卡池分级：部分卡仅挑战及以上入池（低难度池 ⊂ 高难度池）。

## 6. 图鉴系统

- 随时可查看；**遭遇即解锁**（抽到或被作用过即点亮）。
- 新解锁时弹成就式提示动画。
- 三态：未解锁（??? 占位）/ 已解锁未查看（角标感叹号）/ 已查看；打开图鉴若存在未查看卡，自动滚动到最靠前的未查看卡所在行。

## 7. 自定义对局（S5，后期里程碑）

- 通关噩梦后解锁。
- 只能勾选/取消勾选图鉴**已解锁**的卡；未勾选的卡不入池，因此自定义局**不会解锁新图鉴**。
- 其余可配置项（如赛制长度）随 S5 立项再定，S0 不预设。

## 8. 中断、恢复与存档边界

- 竞赛对局**只存在于内存**：返回首页（需二次确认）或刷新页面 = 放弃当前比赛，无恢复——与经典模式（自动存档 + 刷新恢复）的**刻意差异**，roguelike 语义。
- 竞赛存档只记录难度解锁状态与图鉴解锁/查看状态，**无对局细节、无战绩、无历史**；字段与校验见 `../contracts/contest-save-format.md`（S0 草案）。
- 任何模式可随时中断对局并返回首页；经典模式中断行为维持现状（暂停 + 自动存档）。

## 9. 架构落点

- domain 三库：`shared/`（CardId、score、洗牌、事件快照模式、固定牌序测试助手）、`classic/`（现 `game.ts` 平移零改动）、`contest/`（本模式状态机、权重牌靴、AI 策略、卡牌目录）——[ADR-003](../adr/ADR-003-contest-mode-engine.md)。
- 竞赛引擎拥有独立 `transition`/`legalActions` 与事件类型；"先提交后渲染"硬约束同样适用——道具效果全部在竞赛 `transition` 内一次性结算，动画队列只播事件快照。
- UI 流程：首页 → 模式选择（经典 / 竞赛）→ 竞赛进入难度选择页（**难度选择页随 S3 落地**；S1–S2 期间固定标准难度、直接开局）；积分区替代筹码区，新增道具手牌区与坐庄指示。
