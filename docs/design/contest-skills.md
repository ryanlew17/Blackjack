# design/contest-skills — 主动技目录与设计

> 适用范围：技能ID、中英文名、五档场次数、发动信息、逐技效果及机制澄清。
> 何时读取：实现／扩充技能、调整次数或维护技能介绍时。
> 目录登记与执行准入分开；当前可执行范围见[竞赛规则](./contest-rules.md)，实施范围与验收证据见[REQ-027](../requirements/archive/REQ-2026-027-contest-active-skills.md)。

## 目录约定

- 五档顺序为轻松／标准／挑战／危险／噩梦；表中次数是每Match预算，0表示本档不可选，不是道具库存数。资格同时要求难度可玩，不另设技能购买进度。
- 默认每Game最多发动一次，场次数跨Game保留；回仙是明确的次数与当局许可例外。“未停牌”指当前Turn尚未结束，A指数字1。
- 共同的选择、隐身投影、反应／强制行动与结算顺序见[当前竞赛规则](./contest-rules.md#12-主动技战前选择与牌桌)，调度与交互分别见[状态协调](./state-and-animation.md)和[UI](./ui.md)。

探囊／魂迁的“手牌数<上限−1”指道具手牌；默认上限8时最多6张才可发动，保持用户原来的严格边界。灵闻、魂迁等未额外写“未停牌”者仍遵守默认自己的稳定Turn，不可在Hit已提交后插入。替罪只要求对方有明牌，不读取暗牌或总点数决定按钮。

强运的库存存在性与手牌容量只影响执行结果，不是额外发动门槛；缺牌或满手时合法无效果并消耗次数，不提前查询隐藏库存。巧物属于普通库存抽取，使用库存选取随机与已有封锁规则；探囊的随机转移使用独立技能效果随机，不改变库存。

灵闻的“公开”指发动行为公开，牌值仅向发动方的授权观察提供；不产生公共reveal，不将对方逻辑暗牌槽位改为双方公开。只能在自己的稳定行动轮、Hit／Stay提交前发动；对方逻辑暗牌槽位已通过公共揭牌公开时不可发动。发动提示、公共事件和未获授权的视图不携带该牌值；发动方可据此值决策。

变形按发动序号逐项处理，先变换结算基础值，再计算倍率／绑定与同时共生；招灾／嫁祸的随机上界只取共生合并前的有效暗牌值。原始数字实例和牌堆保持原值，结果观察提供结算值及最终总点数。

### 机制约束与理由

- **激发**：监控只记被监控Turn的合法PlayTrump，合法无效果或事后悔牌仍算消费，主动技／Hit补给／费用不算。Turn起始只将待办切为监控，不为空手者补牌、不消耗库存选取随机或断供；其他起始效果仍按共同私有发动序号处理。该Turn结束无回应则保留本Round结算+99，有回应则失效；Round先结束则过期，不能跨回合追加。
- **夺心魄**：三次是普通Hit次数，重担每次可抽两张但仍只门控一次，稳抽与备粮按原规则消耗。禁抽或空堆也要执行自动Stay，这仍是已成功接管而不是零抽牌失效；接管整个Turn不等于调用三次会换人的外部Hit。起始待办与整段续行之间先处理双生花的稳定反应／放行；不能在已提交的三Hit中途插入反应或用卡。
- **魂迁**：布置时立即生成悔牌会通过公开手牌数量泄露隐身发动，改为**成功拦截时**才生成悔牌。若此前Round结束，待办过期且不生成；当时手满则不生成，拦截仍按规则完成。拦截只在原命令合法并消费原卡／费用后发生，同一次PlayTrump不递归重定向；技能奖励先按当前容量生成，再按新效果视角执行卡体，奖励独立于原卡差量。容量／目标失败只使卡体无效果，拦截本身已成功。原方的合法消费仍响应其余粮／从众／激发，效果控制方不因此伪消费。目标回退按稳定枚举顺序，短效和从众以重定向后对象的下一实际Turn定位：对象当前正在行动时为当前Turn+2，否则为+1。
- **双生花**：发动只是秘密布置，快照取本人下一Turn开始时的对方原始明牌值与手牌定义；复制内容不含绑定后的贡献。删除己方旧明牌时移除其绑定和压制依赖，保留己方原逻辑暗牌及index 0、暗牌倍率和其他留场；对方原实例／库存不动，新实例以双生花为来源而不继承原来源特权。双方均无可替换内容时合法无效果，已扣次数不退。反应以可见完整命令边界授权，隐身命令不新增可见窗口；秘密布置后仍由共同放行结束窗口，使对方观察等价。应用自动放行human无法发动的公开窗口及基线AI；组合AI在所有自身反应窗口共用异步搜索入口，选择发动或放行，秘密发动与放行合并一次应用提交。

- **破万法**：取消对方全部待生效技能，无视隐身，生生不息除外，不回退替罪已经移动的明牌或灵闻取得的知识；秘密取消只给技能本人，不补公开布置或次数历史；封锁后不能新布置。库存领取在选取和断供消费前被拦截，包含Round补给、保证及定向领取；普通Hit自身的数字抽取／门控仍走原规则。公共封锁到R+2清理解除，对方禁用持续至Game结束，不能混为同一期限。首个公开帧同步提供施放方生效中与对方锁定状态，不等待清手回放；生生不息不锁定。
- **生生不息**：从本人下一Turn开始，与从众／激发／双生花按共同私有发动序号处理，跨Round保留。选型只取冻结本档数量大于0的已准入定义，按类型等概率而非副本数或剩余库存；只消费skillEffects，满手不采样。首张实际生成才算成功，尚未生成就结束Game记过期。回仙允许的再次发动建立独立生成器；Game结束全部清除。直接生成牌明确标记origin.skillId，转移保留，复制建立新来源，不从sourceId文字推断豁免。
- **回仙**：所选技能本Match至少实际成功一次且余次低于初始上限时，恢复1次及本Game额外1次许可；历史跨Game保留，仅本人canRecover可用于按钮资格。恢复不自动发动、不更换技能、不复活取消待办、不清禁用。恢复与魂迁共用效果控制者语义，悔牌只逆转仍可用的实际恢复额度，不撤销后续发动或知识，不允许负次数／许可；公开上界独立记录差量，避免通过撤销泄漏秘密消费。

## 维护边界

新增技能或调整次数、窗口、效力时，原位更新本表与相关澄清，并同步冻结目录、双语文案和对应实现REQ；登记定义不等于授予执行准入。S3平衡调整与S4技能介绍复用本目录，后续批次与依赖见[长期扩充计划](../roadmap.md#长期主动技扩充计划2026-10-21)。

本文件保留技能目录与设计依据；实施范围、检查与验收记录留在对应需求，行为变化原位更新，不另追加进展段。
