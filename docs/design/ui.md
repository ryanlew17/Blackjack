# design/ui — 界面行为快照

> 适用范围：共享交互、经典与竞赛当前界面、i18n、响应式、动效与音效。
> 何时读取：改组件、样式或用户可见文案前。
> 最后更新：2026-11-10

## 1. 组件与数据边界

```text
src/presentation/
  App.tsx                       # 模式组装、共享设置与统一面板
  shell/ModeSelect.tsx          # 首页经典／竞赛入口
  classic/components/          # 经典牌桌、筹码与动作
    panels/                    # 设置、关于、存档、历史、规则与重置
  classic/format.ts            # 经典金额与牌面格式
  contest/SkillSelection.tsx   # 战前技能介绍、必选与确认
  contest/table/              # 数字牌桌、独立技能球、反应、道具与反馈
  shared/                     # Modal、Icon、系统减少动态偏好
  i18n.ts                     # en／zh-CN字典
  styles.css                  # 集中样式及两模式响应式布局
```

界面只消费应用视图和领域只读查询，不直接访问localStorage、提交完整Match或计算结算。经典金额、数字牌贡献、目标、胜负和积分明细均从对应授权状态读取。NumberCard收到null只挂载牌背与暗牌名称；未公开对手数字、道具、费用身份与秘密技能待办不进入DOM、属性或可访问名。

## 2. 共享文案、布局与可访问性

- 所有用户可见文案进入i18n.ts两个字典；默认语言来自浏览器，手动语言经共享设置保存。长地址允许换行，中英320px均不得横向溢出。
- 技能与道具说明优先写清使用／发动时机、主要效果和必要前提；省略实例、来源、授权投影、逻辑槽位、内部命令与随机分布等开发细节。必要的容量、消耗或封锁例外仍以玩家语言说明，不得为简短而改变规则含义；中英文同步维护，中文说明分别与技能／道具目录的“玩家描述”一致。
- 样式集中在styles.css，无CSS框架；同一属性只留最终生效值，每个断点单一媒体块，媒体覆盖排在基础规则之后。`.table-meta`的`z-index: 1`保留，避免绝对定位庄家层遮挡历史按钮。
- 竞赛及经典All-in、发牌等主操作保持49px；该要求不扩展为全部图标或文字按钮。长手牌／展开道具自然滚动，无固定底栏遮挡焦点、按钮或弹层；不挤压经典牌桌尺寸。
- 原生按钮支持Tab／Enter／Space，radio沿用原生方向键。品牌区非交互；首页Tab首停为静音，牌桌首停为规则，≤760px隐藏规则后首停为静音。模式、准备页与牌桌切换聚焦新标题。
- Modal使用原生dialog限制焦点；Esc、关闭按钮和背景关闭先在DOM连接时close，再通知关闭回调。App面板统一走closePanel清空待导入快照并恢复竞赛；道具选择器仅取消本地选择，不改变暂停状态。程序化关闭在布局清理阶段关闭仍连接的dialog，恢复入口焦点；若道具已消费，退至手牌summary。
- 设置motion取system／reduce／full；useSystemReducedMotion实时订阅系统偏好，Motion与协调器采用同一结果。减少动态保留静态生效／锁定，动画只读事件快照，不回写状态。
- Web Audio合成音效，无外部音频文件；首次用户交互解锁，遵循静音和音量。

## 3. 经典牌桌与共享面板

GameTable显示双方牌、同时存在的两手、当前手、逐手下注／状态／结果；保险和玩家阶段始终隐藏庄家暗牌。hidden Card不挂载正面或牌值属性，初始即牌背，合法揭牌后才挂正面并翻牌；减少动态直接切换。

ControlDeck仅使用legalActions和应用输入锁；保险先显示固定保费、净赔说明及余额不足提示。加倍／分牌／投降的动作提示在按钮下方固定预留一行，优先分牌→加倍→投降，至多一项；不进入Tab序，桌面title作为补充，触屏可读。

HistoryPanel每局一条，包含逐手下注／结果／净收益、保险及整局净收益；mixed不覆盖逐手明细。金额仍为整数百分之一筹码，牌桌显示支持半筹码；经典恢复和冲突见[状态协调](./state-and-animation.md)。

设置、音效与关于跨模式共享；首页不显示重开，竞赛设置仅重开竞赛。关于在同一Modal内切换标题，进入聚焦返回设置，返回后聚焦关于入口；重开弹层回设置首页。显示package.json注入版本、仓库、MIT与GitHub Issues，外链新标签且rel="noopener"，无网络版本探测。

存档面板先校验文件，再显示预览并要求确认；取消清空待导入，不替换进度。version／corrupt状态不显示占位档的摘要或导出，导入仍可用；storage状态保留导出逃生通道。重置与导入取消统一走closePanel；格式及错误语义见[存档设计](./persistence.md)。

## 4. 首页与战前选择

App用内存home／classic／contest选择页面，首次与刷新均回首页。useGame始终挂载，进入经典恢复原有进度和共享设置信封。竞赛通过useContest.start打开SkillSelection；正常App显式s2-development与prepareSkills，固定标准10项可选，不打开难度／图鉴／自定义路由。

SkillSelection显示本档技能名称、说明、场次数，原生单选组不默认预选，未选或paused时确认禁用。界面只用preparation的公开options、selected、paused、inputId调用应用选择／确认／取消；不能预览AI将选何技。确认前不建Match、不消费随机；返回直接回首页，无放弃比赛确认。

确认后AI从同一集合等概率选一次，冻结双方技能和初始次数，再进入牌桌并聚焦标题。准备页新比赛、场中确认重开和场结束新比赛均回空选；旧准备令牌不能启动比赛。S3在选技之前增加难度页，其他档资格由冻结规则支持，不等于已开放正常入口。

## 5. 竞赛牌桌与反馈

### 数字牌与主操作

ContestTable只读MatchObservation，显示胜局、局内积分／递延目标、牌面目标、Turn、双方数字牌、剩余数与行动方。自己暗牌标“仅你可见”，私有窥知不改公共揭牌。手牌可换行，常规2–3张牌在784×803／320×900保持状态、技能和Hit／Stay可达。

Hit／Stay／继续只取应用actions、busy、paused。ContestStatus区分发牌、行动回放、思考、等待技能反应、揭牌及局／场结果；禁用透明度不做渐变。Round／Game结束手动继续，Match结束才提供新比赛，不由页面再次计分。

### 独立技能球与反应

ContestSkills在绒面中部两侧显示双方独立球形技能区，不加入Hit／Stay行。本人球58px、窄屏48px，只提交当前skillCommands；对方球只读不可代发。双方名称按钮打开公开说明与初始次数，并暂停比赛。

本人显示准确场次数及本Game已用状态，对方只显示授权次数／范围／未公开状态。可发动、待生效、生效中、无效果、取消、过期和锁定取当前观察；不得以秘密状态推导对方提示或禁用原因。busy／paused／道具选择期间禁用发动；回仙恢复后由新合法命令重新启用，不自动发动。

破万法首个公开帧同步施放方生效中与对方锁定，不等逐张清手；生生不息豁免，持续生成时再次布置仍显示生效中。生效中保持到公共封锁及对方Game禁用均结束，减少动态保留清晰静态状态。秘密取消不补公开布置或真实次数历史。

双生花在对方完整命令之间开放技能球与独立放行，状态栏说明选择；不抢焦点、不设倒计时或靠动画间隙抢点。放行不耗次且焦点回本人说明，Esc关闭说明不等于放行。暂停／恢复后旧inputId失效，已放行的领域边界不重开。

### 道具选择与留场

主操作之后默认收拢本人手牌与双方留场。本人可看效果／条件，对方仅公开数量和库存计数；合法用卡才显示可用。TrumpChooser仅从trumpCommands中选择完整明牌／留场目标、交换目标、费用与公开声明，点击使用才提交，无二次确认。非法卡可读条件但不能使用；指定抽取与截流不预告隐藏成功。

Esc／取消零消费并恢复焦点；busy、暂停或代次变化关闭旧选择，不保留待提交输入。每张卡回放后按权威行动方恢复，同Turn可继续用卡。悔牌关闭提示只读公开原因，不查询逆操作差量。

留场显示控制方、压制、绑定对象、原到期玩家＋Turn、触发余量与从众记录；移花不更改绑定或到期。共生只显示待结算提示，倍率不暴露未知暗牌贡献；有效总点数／目标来自观察。

### 授权反馈

ContestFeedback最多48条授权事件，覆盖抽取／生成／删除／转移、零领取、放置／清理、悔牌窗口及技能结果。对手null身份是私有遮罩，不误报失败；秘密发动只给本人。窥序失效后历史不重放位置数值，悔牌反馈不点名未知撤销对象。

round-scored直接显示权威基础分、攻防、封顶、护身／息战及各来源，清理后仍可读；组件不另算胜负。回仙按效果控制者说明实际恢复1次及本Game额外1次许可、既有禁用继续生效。54个道具定义和15技能均有双语名称／条件／结果；标准库存61且回仙为0，其他档卡不因此进入标准库存。

## 6. 离开、暂停与后续入口

规则／设置／技能说明／离场确认通过App暂停竞赛，统一closePanel恢复。场中返回首页或重开要求确认，取消／Esc／背景关闭继续原比赛；确认exit取消旧队列／对手任务，重开重新必选。场结束且没有弹层时的新比赛直接restart；设置弹层中的场结束新比赛仍走确认。刷新丢弃内存比赛，不恢复竞赛牌面或保存技能待办。

AI战前均匀随机选技，场中根据授权观察搜索道具／技能组合；每次只提交一步，回放后重新决策。思考期间显示忙碌状态，打开弹层或页面不可见时取消当前搜索，恢复后从当前状态重算。完整图鉴页仍在S4，技能独立页／页签介绍条件与五档场次数，不复用道具遭遇三态，也不将技能ID填入CodexProgress。当前行为的验证与未覆盖边界留在对应需求，不在本指南追加进度或验收日志。
