### 共用与逐卡边界

- 所有卡仅在自己 Turn、命令未锁定时使用；使用不结束 Turn。非法使用不消费、无事件、不消耗随机；合法消费重置安静停牌记录，失败效果也如此。
- 指定抽取不得根据暗牌位置禁用按钮；即使公开已知该数字不在堆中，本实验仍允许消费后失败。空堆也可失败消费，不凭真实堆状态预告成功。
- 收回／驱离需要对应方有明牌；易位需要双方有明牌。公开条件不满足时拒绝。退牌回到未发数字集合，下次普通 Hit 由注入随机从集合抽取；不重新发初始牌，不创造牌。
- 拆解／清场需要对手存在留场卡；仅清除持续效果，不撤销已执行的抽牌。按放置序号判断“最近”，不是数组偶然顺序。
- 目标牌全局互斥，新牌移除旧牌；清除当前目标恢复 21。先验证使用者原桌面少于五格，再替换目标：即使旧牌属于自己，原桌面已满仍拒绝（保守实验口径，S2 可另议）。
- 精准抽牌：在剩余数字中，优先取使自己总和不超过当前目标的最大数字；没有则取最小数字；空堆消费后失败。此算法是本项目建议，不宣称原版算法。只能返回实际抽到的公开牌，不输出候选列表或对手暗牌。
- 留场卡至 Round 结束、被清除或替换时离场；计分效果同类可累加，但受下文总上限约束。战备施压先检查五格容量，再补牌并留场；即使库存空或手满导致补牌失败，积分部分仍生效。
- 整备额外弃牌是公开数量、隐藏身份的成本；剩余手牌不足一张时拒绝，不能先补后弃。领取多少取决于库存和容量，不因少领返还成本。
- 余粮安装时不触发自身，触发后剩余次数递减，归零离场。每次其他卡消费可触发每个已在场的余粮实例一次；领取资源事件不算使用卡，不递归触发。使用第二张余粮可以触发先前那张。
- 对手身份隐藏：获得道具只公开数量；使用后身份公开。废弃手牌的身份不公开，不触发对手图鉴；公开留场离场保持其已知身份。

## 2. 积分改编方案 P0

原版的代价映射为“获胜方额外得分”和“失败方抵消额外失分”，单位是整数积分，完全不使用经典的百分之一筹码单位。

当 A 赢时，令 `a` 为 A 有效进攻留场卡的加分总和，`d` 为 B 有效缓冲的抵消总和：

```text
A 本回合所得 = 1 + min(2, max(0, a - d))
B 本回合所得 = 0
平局双方所得 = 0（忽略积分修正）
```

先抵消，再封顶；不是分别对双方乘倍数。无抽牌或用卡即时得分。胜者至少 1、最多 3 分，避免双方一直靠防御制造 0 分胜负回合；若以后需要完整 Shield 的 0 分玩法，另做方案 P1 的时长实验。

| 情况                         | P0 预期                             |
| ---------------------------- | ----------------------------------- |
| A 赢，双方无积分卡           | A +1                                |
| A 施压，B 无缓冲，A 赢       | A +2                                |
| A 施压，B 缓冲，A 赢         | A +1                                |
| A 施压，B 赢但 B 无进攻卡    | B +1；A 的施压不替 B 加分           |
| A 进攻合计 4，B 缓冲 1，A 赢 | A +3；先 4−1，再上限 2              |
| 双方同点／双爆同点           | 0:0 增量；照常推进 Round 与先手轮换 |
| 当前 3:4，A 得 2，目标 5     | 5:4，A 直接胜局，不补造 4:4         |
| 当前 3:4，A 得 1，目标 5     | 4:4，目标递延至 7                   |
| 当前 6:6，目标已为 9，A 得 3 | 9:6，A 胜局                         |

执行顺序：最终牌面判胜 → 汇总仍有效修正 → 一次性加分 → 判断同分到目标减一并递延 → 判断局／场胜 → 清理留场。不得提前清理积分卡再算分。

## 3. 资源模型实验 F1

为了让“几张”有明确含义，首个实验采用**每方独立有限库存、Game 内不回收**。这只是候选模型；S2/S3 可比较可回收模型后再定稿。

- 每方按表中的张数建立库存；同档双方资源一致，同一 Match 冻结全部配置。每次从自己的剩余实例中均匀抽一张，因此概率随库存变化，不把张数当作固定掉落百分比。
- 每 Game 开始先发 2 张；每 Round 发初始数字牌后双方各补 1 张，所以首 Round 最多持 3 张。普通 Hit 不额外发道具，道具数字抽取也不附赠；此实验故意隔离掉落变量。
- 持牌上限暂定 8，桌面上限沿用 5。多张补充按顺序逐张领取；手满时停止领取，未领取实例留在库存，不销毁；库存空则发放 0 张。所有实例在库存／手牌／桌面／弃置中恰占一处。
- 消费的即效卡、支付的弃牌及离场卡进入本方弃置区，本 Game 不再抽回。Round 结束只清桌面，保留手牌、库存和弃置；Game 结束全部重建。不会从对手库存借牌。
- 每方各档总库存为 **16 / 22 / 26 / 29 / 30**，双方总量为其两倍。纯即效最多消费有限实例；补充卡也只搬运库存，不能创造新实例，故一 Turn 无限资源循环不可达。数字牌另行维持 1–11 唯一性。
- 自定义只能从已选定义建立同一套双方库存；不偷偷加入反制卡。含积分卡至少选缓冲或拆解之一，含目标卡至少选拆解；否则拒绝配置并说明缺项。这只是 S5 的依赖校验候选。

## 4. 暂缓或排除的研究方向

以下仅按机制归组定位，详尽卡面与费用继续从来源核验；没有给它们虚构正式难度和库存。均为“不入 F1”，数量 0，图鉴正式目录也不纳入。

| 原版参照                                        | 改编考虑                             | 当前决定                                         |
| ----------------------------------------------- | ------------------------------------ | ------------------------------------------------ |
| Two-Up+、Perfect Draw+、Ultimate Draw（W2、G2） | 双重强效果容易同时提高牌面和积分优势 | 先验证战备施压这一种混合卡，再比较升级卡         |
| Shield+、Trump Switch+（G1）                    | 防御成长与大额补充                   | 不自动用升级版替换基础版；避免重复图鉴和资源膨胀 |
| Destroy++、Dead Silence（G2）                   | 长时间禁用道具或数字抽取             | 暂缓；未来可评估短效封锁，必须保留明确反制窗口   |
| Desire、Mind Shift 系列（G2）                   | 按资源计价／弃手牌压力               | 后续逐卡核实，再考虑有上限、低损失的版本         |
| Shield Assault 系列、Curse、Black Magic（G2）   | 牺牲资源换强攻                       | 先补成本、隐藏信息与爆牌挽救测试                 |
| Twenty-One Up、Desperation（G1、G2）            | 巨额代价压缩胜负                     | 排除原版数值；不允许一张卡直接颁发 Match 胜利    |
| Oblivion、Escape、Love Your Enemy（G2）         | 回合取消、敌人退出与剧情解法         | 不照搬；需要额外规则变更，不能旁路既定 BO-N      |
| 数字 1、8–11 的指定抽牌与增强版本（G2）         | 卡池拓展                             | 证据范围未统一，暂不创建候选定义                 |

## 5. 后续定稿证据

S2 先验证指定抽取失败、满桌混合卡原子性、退牌守恒、目标替换、连续用卡、资源耗尽和结算顺序；S3 再验证五档配置。图鉴需覆盖自己领取、对手公开使用、未公开领取、查看状态、自定义禁止新解锁。

平衡实验建议固定多个种子，对每档和双方先手分别采样；记录胜率及置信区间、Game/Match 回合数与耗时、平均/最长用卡链、库存耗尽率、各卡使用与胜率相关性、赛点跳分频次。先跑小样本找规则问题，再约定样本数与接受阈值；当前没有任何模拟结果，表中张数不代表公平性已证实。各难度保持同一 AI 策略与预算。
