# 道具卡与图鉴研究资料

研究日期：2026-10-18（纯资料收集，不独立登记需求）

本目录是竞赛模式的前期研究与可讨论草案，尚未实现、未做平衡模拟。正式规则仍以 [竞赛基线](../design/contest-rules.md)、[ADR-004](../adr/ADR-004-contest-turns-and-shared-boundaries.md) 和后续实现需求为准。

建议阅读顺序：

1. [来源与原版机制](./sources.md)：来源可靠性、代表性卡片、资料分歧与待考证项。
2. [候选卡与积分实验](./candidates.md)：21 张候选定义、五档张数、计分与资源方案、暂缓项。
3. [数据结构草案](./data-model.md)：定义、运行实例、难度配置和图鉴的边界及示例。

所有中文卡名均为本项目暂定名。英文参照名仅用于检索，未来产品名称与说明须进入 i18n 的 en / zh-CN 双字典。本次不采集原版图片、音频或整段文案。

“难度解锁”在本资料中指最早允许出现的难度，不代表自动解锁图鉴。图鉴仍以公开遭遇为准；对手未公开的手牌不能解锁条目。张数是每方每 Game 的实验库存，不是原版掉落数据，也不是数字牌堆的构成。

数据层后续工作见 [REQ-2026-013](../requirements/archive/REQ-2026-013-codex-data.md)（已验收归档）。研究参数仍未平衡定稿。
