## 背景

15 项主动技与 54 张道具的玩家说明混入了实例、授权投影、逻辑槽位、随机分布和内部命令等开发概念，新玩家难以判断何时能发动以及会产生什么效果。用户在主动技目录新增了描述草案；本项据此统一重写玩家可见说明，同时保留面向开发者的完整机制边界。

内测另发现替罪依赖公开确认爆牌，实际很难发动；激发为对手补牌也削弱了施压意义。本需求继续在同一 S2 收尾项内调整两项技能：替罪只保留转移对手末张明牌，激发删除对手补牌但保留未用道具的 +99 惩罚，使清空对手道具成为可主动构建的配合。

## 方案要点

- 直接维护两个 i18n 字典中现有的 `description` 键；中文与英文分别使用本模式已有术语，优先说明使用或发动时机、核心效果和必要限制，不堆叠引擎安全边界。
- 保留 `contest-skills.md` 的“条件与效果”及机制澄清，将新增列定稿为“玩家描述”；`contest-trumps.md` 基础 51 卡增加同名列，悔牌／回仙／赌命在运行契约章补充玩家描述，不删除既有开发说明。
- 在 UI 指南记录玩家长文案的写作边界；沿用现有字典覆盖测试，不新增逐字或禁用词断言，以免把合理的文案调整误判为回归；语义与可读性通过文档对照和真实页面抽查。
- 道具基础表从 7 列扩为 8 列后，同步调整架构、资源、效果测试及供应脚本的表头计数，既有字段索引不变。
- 替罪仍限自己的稳定行动轮且对手必须有明牌；合法发动立即转移末张明牌并记成功，不再判断公开爆牌、记录点数快照、生成待办或在结算时随机减点。
- 激发仍在对方下一行动轮监控实际道具使用，未用道具则本回合结算 +99；删除行动轮开始前的库存补牌及其与库存、断供的联动，不修改其他 Turn 起始效果。
- 先通过领域测试复现旧行为，再修改实现；同步更新开发者规则、双语文案与受影响的应用／组合测试。

## 验收标准

- [x] 15 项技能及 54 张道具的中英文 `description` 均改为通俗、准确的玩家说明，能判断主要使用时机、效果与关键前提。
- [x] 技能与道具文档均保留原开发者描述，并提供与最终中文玩家文案一致的新列；UI 指南包含后续维护约定。
- [x] 替罪在对手有明牌时即可发动，无需爆牌或任何公开信息门槛；只转移末张明牌，立即记成功，无随机减点、点数快照或待结算效果。
- [x] 对手只有暗牌时替罪仍不可发动；既有次数、每局许可、实例／绑定转移、投影及悔牌边界不回退。
- [x] 激发不再为对手补牌，空手对手可停牌并在结算承受 +99；合法用卡仍免罚，其他回合起始效果与随机流不回退。
- [x] 两项技能的开发文档与中英文说明一致，受影响领域／应用／AI 组合测试更新并通过。
- [x] 全量测试、严格类型检查、格式化、差异检查与真实页面抽查通过；最终证据并入本需求。
