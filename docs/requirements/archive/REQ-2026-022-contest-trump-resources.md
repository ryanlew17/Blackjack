## 背景

S1 TrumpSetup 是私有固定资源夹具，仍用 table／discarded 保存打出的牌实例，缺少真实库存和生成／删除。用户要求下一项统一修改规则与现有代码；本需求承接该修改，不在规则登记阶段先改运行行为。

[51卡设计](../../design/contest-trumps.md)与[数学实验](../../../scripts/validation/contest_supply_model.py)保留为历史基线。本需求追加3卡后为54个定义；此前“全渠道领取上限”“绝不复制数字”“每局 PlayTrump≤2M”等结论只适用于旧模型，不能用于有生成与主动技的新模型。

## 1. 资源与销毁契约

- 每方每Game建立独立有限道具库存。普通抽取对每个剩余实例等概率、无放回；普通抽取与定向检索均只移走实际剩余副本，不重置额度、不回收已领牌。Game开始2张，每Round初始数字牌后按先手／后手各补1张。
- 普通Hit的额外道具门控仍为轻松／标准／挑战／危险／噩梦20%/30%/40%/50%/60%。效果抽数字、退牌、交换、生成、转移不额外触发Hit门控；一次Hit即使抽多张数字也只门控一次。
- 持牌上限8，留场效果上限5。手满不领取、不销毁库存、不延迟补领；零张领取不消费选取随机，合法普通Hit仍消费一次门控。多张补给逐张执行，容量不足只取得能容纳部分。
- **道具卡一经合法打出即销毁**，合法效果失败也不回到手牌或库存。费用中移除的牌也不可再抽回。非法命令不销毁、不付费，返回同一状态引用、零事件零随机。
- 持续效果以独立“留场效果记录”存在；它可以保留来源定义／原实例的审计标识，但不是仍活着的卡体，不能回收或复活。五格容量约束记录；清除只移除效果，不撤销已执行的即效部分。
- 自己被替换的目标效果可以释放己方位置，对方位置不能抵扣；满桌混合卡在任何付费、抽取、销毁之前完成容量预检。保留可失败放置的明确失败语义。
- Round清理回合级效果，保留手牌与剩余库存；Game清空旧资源／局级效果并按冻结配置重建。Match结束、退出、重开无残留；无对局持久化。
- 不增加极端抽尽应对项目。资源原语对没有剩余副本自然返回0，不能凭空补牌；正常Hit／Stay继续合法。REQ-021供应实验不证明新生成模型的实际耗尽率或五档胜率，后续正常对抗数据如实记录即可。

## 2. 生成、删除与转移

| 术语          | 权威操作                               | 不随之发生的操作                                  |
| ------------- | -------------------------------------- | ------------------------------------------------- |
| 抽取 Draw     | 将库存或数字堆中的既有实例移至目标区域 | 不创建副本、不放回道具、不自动打出                |
| 生成 Generate | 按明确效果创建一张具有新实例ID的牌     | 不扣库存、不消耗既有副本、不改其他牌、不默认算Hit |
| 删除 Delete   | 从当前区域移除指定活实例并记为已删除   | 不退回牌堆／库存、不顺带抽取或生成其他牌          |
| 转移 Transfer | 改变既有实例的持有者或区域             | 不生成副本、不改原始来源、不消耗接收方库存        |

定义数量表约束**每方初始库存及其库存抽取**，不是所有获得渠道总上限。清场每方每Game至多从自己的库存抽到1张；探囊转入或明确生成同定义不额外扣己方额度。从众／强运仍须找到自己库存中的真实副本，不能再抽到已抽走的那张。数字牌“收回”可将该数字实例放回数字堆，与道具不放回无冲突。

每Round初始数字牌仍为1–11各一张；生成可以产生同值新实例，删除可以让初始牌不再留在手牌／牌堆。始终保证实例ID唯一和单一活区域，按来源记录“初始＋累计生成＝当前存活＋累计删除”；不能继续断言永远恰好11个活数字或把相同牌值当成相同实例。数字牌贡献、暗牌槽位与显示分开建模，保持S1无生成配置的既有行为。

生成何种随机道具由效果明确：REQ-027生生不息在当前难度副本数>0且已准入的定义集合中均匀选一个定义，不受剩余库存影响；固定生成悔牌不随机。生成也受目标手牌上限约束，满手跳过，不建立溢出暂存区。双生花复制的是牌内容，新ID和新的生成来源不继承对手来源豁免。

## 3. 新增三卡与五档限量

数量顺序为轻松／标准／挑战／危险／噩梦；仅为各方每Game初始库存副本，0表示该档不在普通卡池中。中英名与ID在实现时写入唯一目录及两份字典，不重加“最早出现”字段。

| 定义ID          | 拟用名称            | 库存副本  | 效果与实施归属                                                                                                                   |
| --------------- | ------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `regret`        | 悔牌 / Take Back    | 2/3/3/4/5 | 撤销上一手道具的效果，或将上一手数字牌放回数字堆；不执行Hit。022定义事务与数字实例接缝，023实现效果差量及撤销。                  |
| `skill-revival` | 回仙 / Reawaken     | 0/0/0/1/1 | 主动技已发动且成功生效后恢复1次场级次数，并额外开放本Game一次发动；022定义契约，024预留局级效果接缝，027完成可用性及端到端准入。 |
| `sudden-death`  | 赌命 / Sudden Death | 0/0/0/0/1 | 令本Round的胜负直接决定本Game胜负；平局顺延至下一Round。024实现局胜通路，不直接赢整场。                                          |

54卡初始库存合计为**39/61/73/76/78**，分别等于原37/58/70/71/71加新增2/3/3/5/7。普通每实例等概率不变，逐定义占比随总量重新计算；不把021旧概率表或500,000样本结果改名当作新54卡验证。S3需把主动技、转移、生成一起纳入真实策略对抗评估。

### 3.1 悔牌的事务边界

“上一手”取当前未结算Round最近一次已提交的出牌事务，双方均可成为原出牌者；Stay不是出牌，不覆盖该记录。主动技生效、自动阶段变化等若已改变这笔事务涉及的状态，则结束该撤销窗口，不能越过这些变化回滚历史。不得跨Round／Game或撤回已提交的结算。

- 上一手为数字出牌：退回那笔事务最后取得且仍在场的明牌实例至数字堆末尾；初始发牌不算上一手。普通Hit的已发生补给不倒退，不恢复已结束的Turn或重走门控；强制多张抽取也只退最后一张。暗牌仍不可退。
- 上一手为道具：按该事务记录的效果差量撤销即效及留场；原道具、费用牌仍已销毁，已付次数／资源不退，不回滚真实随机游标、行动权或安静停牌记录。悔牌自身也销毁，后续悔牌可对其新效果事务撤销，不能复活原卡。
- 撤销“生成”就是删除其生成实例；撤销“删除”按原内容生成新ID，不能复用已删除实例ID；撤销库存补给删除所得牌，不将它们放回库存。转移可在窗口内反向转移；恢复被清除的持续作用创建效果记录而非卡体。
- 已见信息不能从双方记忆／观察历史中抹除；悔牌不能让已经获知的数值重新变成未知，也不能靠重放随机重新抽签。随机、多段、定向抽取、替换、失败效果和魂迁重定向都记录实际差量。
- 若没有可撤销出牌事务则公开不可用。合法但原效果为零的事务可以撤销零效果并消费本卡，不据隐藏真值预告“有无收益”。023须用逐项实例断言冻结上述窗口，不实现任意历史快照回滚或第二套结算器。

### 3.2 回仙与赌命

回仙只在本Match所选主动技至少有一次**成功生效**、当前剩余次数小于其初始场上限时可用；只有待生效／被取消／纯无效果不算。恢复1次但不超过初始上限，同时给本Game增加一次发动许可，明确豁免“一局最多一次”。不自动发动、不换技能、不恢复被取消的待办，也不解除破万法的显式禁用。技能次数、许可和已成功生效记录在027统一实现；无主动技配置不得发出有名无实的生产回仙。

赌命设置公开局级标记，不提前结束Turn或绕过两次安静Stay。当前Round决胜方直接赢本Game，护身0分不能阻止该局胜；平局（包括双爆同点）不判局胜，标记延续至下一Round；作废不等于决胜。只颁发一次局胜，Match仍按原先所需胜局数判断。标记已存在时公开拒绝重复；结算前可由悔牌撤销，Game清理时移除。常规分数／递延仍可展示，但不得重复颁发局胜或虚构大额加分。

## 4. 实现清单与后续分工

1. 修改既有 `engine/effectTypes.ts`、`effects.ts`、投影／清理与相关测试，取消“已打出实例仍活在table／discarded”的模型；销毁审计与留场记录分开。不要以新增另一套引擎绕过原型回归。
2. 建立抽取／定向检索／生成／删除／转移的最小纯TS操作，冻结54卡数量配置及实例来源，先校验初始化再消费随机。公开配置与私有库存分离。
3. 真实随机分离数字洗牌、Hit门控、库存选取；027再接技能选择与效果源，028接搜索源。零领取、手满、非法命令的调用次数有确定契约。
4. 为023悔牌、024赌命／回仙效果描述和027主动技提供必要状态边界。022本项不宣称三卡全部已可玩；025准入51旧＋悔牌／赌命共53卡，回仙在027主动技就绪时完成第54卡准入；026先展示已准入的53卡。
5. 023/024逐卡按最新销毁／效果记录语义实现；025禁止旧discarded实例重新入池；026展示实际取得渠道与删除／失败反馈；027实现生成类技能、回仙和隐身；028最后开发全部54卡＋15技能的组合AI。

有限库存本身已不能证明有生成玩法时每局最多2M次出卡。本项只保留每命令触发队列可终止、领取不递归触发、有限触发次数、Turn-start处理幂等等依据；不为无限长平局或合法连续用卡设置暗中上限，也不以搜索深度限制玩家行动。

- CardTransaction保存上一手实际差量，SkillUseRecovery／SuddenDeathMarker保留后续类型接缝；完整状态、库存身份、费用审计及撤销差量不进入他方观察。
- 本项正常生产入口仍为无道具标准BO5；hitDrawCounts只提供抽1／2张接缝，不代表重担或三张新卡已完成执行。

## 验收标准

- [x] 固定序列覆盖Game／Round补给、普通Hit门控、多张部分领取、手满及双方库存隔离；同一副本不能从自己库存领取两次。
- [x] 原型、正式模型与逐事件帧均证实出卡即销毁，失败同样消费、非法零副作用；留场仅是效果记录，Round／Game清理不复活卡体。
