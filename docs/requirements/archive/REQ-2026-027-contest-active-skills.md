## 背景与范围

在S2末项组合AI之前交付全部15主动技、战前选择与牌桌交互，复用道具的权威状态机、授权投影和提交／取消机制。正常入口固定标准难度；五档入口与平衡留S3，主动技独立图鉴页留S4。不新增技能养成／购买、对局存储或组合搜索；后续扩充见[长期计划](../../roadmap.md#长期主动技扩充计划2026-10-21)。

## 实现摘要

- 15技执行、五档场次数、默认每Game一次及回仙额外许可完整接通。合法发动即扣次，后续无效果／取消／过期不返还；成功历史跨Game保留，局内许可与待办按生命周期清理。
- 标准战前10项必选，确认后从同一集合等概率抽取AI一次并冻结双方身份；取消不建场、不消费随机，重开回空选。技能选择、真实效果与其他随机流独立，非法／陈旧命令零副作用。
- 灵闻私有知识及变形／魂迁／双生花隐身均经观察、事件和DOM授权；稳定反应／放行、受控3Hit、Turn起始待办、结算／先手覆盖由同一权威命令链执行，动画只回放已提交结果。
- 魂迁控制权与原方成本分离，生成／删除／转移保留实例账与逻辑暗牌。破万法无视隐身取消待办，首帧同步施放方生效中与对方锁定，生生不息明确豁免；封锁期限为R余下＋R+1＋R+2，对方技能禁用独立持续至Game结束。
- 回仙作为第54卡正式准入，五档库存39/61/73/76/78，标准61且回仙0；双方独立球形技能区、中英反馈、键盘与减少动态支持完成。共享弹层关闭及导入预览取消的焦点恢复已修复，经典规则与存档格式不变。
- [状态指南](../../design/state-and-animation.md)、[UI指南](../../design/ui.md)按当前职责归并，规则、架构、目录与模块说明同步。AI仍沿用S1无道具／无技能自动决策基线；组合发动与搜索由REQ-028实现。

## 验收标准

- [x] 15项定义及五档次数逐项一致，可用数量7/10/13/14/15；选技资格、取消零随机、AI等概率抽取一次、双方公开身份与Match冻结通过；无另设最早出现／技能购买进度。
- [x] 逐技覆盖合法／非法、成功／无效果／待办取消／过期、Game清理与跨Game场次数；一局一次、回仙补次数／额外许可与不解除禁用均有确定断言。
- [x] 灵闻五档场次数为1/2/2/3/4；发动行为公开、暗牌值仅向发动方授权，不触发公共揭牌或改变全局公开状态；仅自己的稳定行动轮可发动；错误行动方、Hit／Stay已提交或对方已公开时拒绝，零事件零随机、不扣次数；公共事件不泄漏数值。
- [x] 变形、魂迁、双生花布置前后对方公开观察／事件／安静记录等价，实际生效才揭示；本人仍获准确私有状态。替罪与强运按钮不查询未知真值。
- [x] 对方Turn反应／放行、连续命令边界、重复恢复、受控3Hit／禁抽／空数字堆、暂停／重开／退出／旧回调均按权威命令验证，不以动画时机决定效果。
- [x] 生成／删除／转移的实例账、数量不影响库存、同值数字新ID、暗牌保留、来源免疫，以及魂迁重定向／满桌失败／悔牌实际差量均有交叉用例。
- [x] 外审承接的首位暗牌不变量通过；技能生成不插入index 0，双生花保留己方原暗牌ID与位置，trim、明牌目标及共振计数不因新实例偏移。
- [x] 变形→倍率／共生→点数增减→判胜→赌命／积分→先手覆盖的顺序及随机上界、最低0、平局／跨Game／Match终止边界一致；所有结果只提交一次。
- [x] 破万法R余下＋R+1＋R+2、Game提前解除、公开／隐身待办均取消、新发动受禁、同帧生效／锁定及生生不息显式豁免分别覆盖。
- [x] 技能真实随机与选择／搜索／普通资源流隔离，相同观察与种子下可复现；回放不消耗随机，非法命令零随机，纯TS域检查通过。
- [x] 回仙完成第54卡生产准入及双语／UI反馈；固定标准可完整比赛。浏览器覆盖战前选技、独立球形按钮、一次限制／剩余次数、反应放行、双方技能信息，中英、784×803／320×900、键盘、减少动态与经典刷新保存回归；实际覆盖／未覆盖边界写入本需求。
