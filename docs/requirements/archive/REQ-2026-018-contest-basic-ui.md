## 背景

在经典兼容检查点之后增加模式入口，交付可操作的固定标准 BO5 竞赛界面；这一步才允许出现新的用户可见功能。

## 方案要点

- 提供首页／模式选择入口，经典仍可完整游玩并恢复既有进度；进入竞赛启动固定标准无道具 BO5，明确当前阶段范围，不展示尚未实现的难度／图鉴／自定义入口。
- 展示大比分、小比分、当前胜局目标分、牌面目标、当前行动方及双方公开数字牌；自己暗牌自己可见，对手暗牌到揭牌才公开。
- 提供 Hit/Stay、回合／局／场结果与继续／重开操作；状态与动作来自应用层，不在组件里判断输赢或积分。占位对手通过 REQ-017 接口驱动。
- 进行中的竞赛返回首页需确认放弃；取消确认继续当前比赛；刷新进入默认入口而不恢复竞赛。切换经典时不损坏其保存进度或设置。
- 所有新增文案进入 en/zh-CN 字典；遵守键盘、320px、减少动态效果与动画输入锁。道具原型的测试夹具不暴露为生产功能。

## 验收标准
