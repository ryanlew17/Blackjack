## 背景

无道具比赛无法证明未来连续用卡、目标替换、爆牌挽救与动画边界正确。本项用最小真实命令链验证 S2 效果入口，避免在基础 AI 完成后才发现底层需要重写。

## 方案要点

- 用显式注入的固定数字牌、道具实例与最小测试规则快照，仅选择指定抽牌、收回、目标变更、清除留场，以及一个“使用时效果 + 留场效果”测试定义。混合定义可使用抽数字牌加目标变更，不提前裁定积分道具或资源模型。
- 命令必须经同一竞赛 transition/合法动作边界，不能让测试通过直接修改状态模拟成功。同一个 Turn 可连续用卡，PlayTrump 不换人，合法消费包括效果失败都打断安静停牌；非法命令仍零消费。
- 验证明牌退回与数字牌守恒、指定抽牌失败不提前泄密、爆牌可挽救、目标牌全局替换与清除恢复 21、满桌混合卡先校验后执行。
- Round 清理留场与目标，Game 清理道具手牌／资源；清除不能回滚已经完成的即效。必要的实例状态仅限原型，不把 F1/P0 或 21 张候选直接标记可玩。
- 双方需要用卡的反例由测试驱动明确提交双方命令；正常占位对手仍只 Hit/Stay。测试入口、固定夹具与原型资源不得从生产首页可达，不添加隐藏运行时调试开关。
- 将已证明的命令／事件／投影／应用接线接口回填设计，明确实验部分和 S2 待定部分。

### REQ-018 人测追加：页面体验修整（2026-10-20）

用户在 REQ-018 四项人工测试通过后，明确要求将三条非阻塞观察加入下一项需求一并处理；本项正式道具界面仍为非目标，不把原型测试入口接入生产首页。

1. **短视口主操作可达性**：桌面 784×803 与移动 320×900 下，竞赛 Hit／Stay 常需滚动到首屏外。优先通过压缩无效留白或自适应操作区改善常规手牌的操作可达性；如采用吸底，确保不遮挡手牌、比分、焦点或弹层。长手牌允许纵向滚动，不能以缩小触达区域换取首屏容纳。
2. **经典暗牌 DOM 隐藏一致性**：当前经典庄家暗牌视觉／可访问名称正确，但翻牌动画正面数值仍在 DOM，这是 REQ-018 前的既有表现。调整展示，在合法揭牌之前不挂载暗牌数字／牌面文字或值属性，揭牌后再呈现真实正面；保留现有视觉、翻牌／减少动态、经典刷新恢复和先提交权威状态的边界。不扩展为存档加密、防作弊或改写经典规则。
3. **行动节奏与反馈复核**：原报告认为每次约 0.6s（回放 + 300ms 思考）的节奏自然、无卡顿，此项不是已确认时长缺陷。结合短视口操作区调整复核「对手思考／回放／你的行动」反馈的可见性与多次要牌的连贯感；保留当前延迟作为基线，不预设加速、不添加难度或速度设置。必要调整仍须保留输入锁、减少动态与退出／重开取消语义。

## 验收标准

- [x] 真实命令链证明连续用卡后 Hit/Stay 只换人一次；用过道具后双方各 Stay 不误结算，随后安静停牌正确结束。
- [x] 覆盖指定抽取失败、暗牌保护、退牌守恒、爆牌挽救、目标替换／清除及重复清理安全性。
- [x] 覆盖桌面五格已满时混合卡原子拒绝，纯即效仍可用；清除不撤销已完成即效。
- [x] 应用测试证明每张卡动画后恢复同一方行动，权威结果不由动画回调决定；双方操作夹具不等于 AI 会用卡。
- [x] 正常无道具路径仍关闭道具发放，未接图鉴、未准入全部候选，生产页面不可进入测试原型。
- [x] 已验证接口与 S2 未定项有明确记录；经典回归和实施时质量门槛通过。
- [x] Chromium 实测桌面 784×803 与移动 320×900：常规双方各 2–3 张牌时，主操作在首屏内可达；九张长手牌可滚动查看，操作区不遮挡内容、焦点或弹层，双语无横向溢出，触达面积不降低。
- [x] 经典暗牌在合法揭牌前的 DOM／可访问名称／属性均不含牌面值；揭牌／动画中刷新恢复、完整与减少动态、经典一手及保存往返无回归，视觉与原交互保持一致。
- [x] 调整后能清楚区分并看到 AI 思考、事件回放和玩家可操作状态；连续要牌流畅，快速重复输入与思考／回放中退出／重开均无重复推进或旧回调；记录实际节奏，不将约 0.6s 的正向观察直接视为加速要求。
