## 背景

用户将原15卡下限扩展为40+不同类型的道具系统，允许广泛改编非剧情卡。旧21卡F1/P0只用于前期研究，旧“最早出现”不再是配置字段。本项以 [51卡表](#a-51卡规则限量与概率) 定稿规则，明确普通抽取的等概率含义与强效卡限量，不把未实现运行时宣称已完成。

## 方案要点

- 51个定义、合并数字／目标变体后44组机制；全部纳入S2设计，覆盖原21卡和30种新增卡。数量仅由五档非负副本表决定，earliestDifficulty已从现有候选类型与预设移除，51卡精确ID／运行定义由025扩展。
- 每方每Game独立有限库存，普通抽取每个剩余实例等概率，无放回、不回收、不复制；收回3/4/4/5/5，清场0/1/1/1/1，强效／高效多数每局1张。副本额度约束所有领取渠道，包含从众。
- 五档普通Hit额外补给门控为20%/30%/40%/50%/60%，只影响额外资源，不替代数字牌。Game初始2、Round初始1、手持8、桌面5；普通领取、定向检索、耗尽／满手与随机调用见卡表§3–5。
- 采纳P0一般积分公式和1–3分区间，增加护身显式0分特例；分数跳跃、平分递延、判胜／清理顺序确定。
- 明确共生的同时结算公式、暗牌倍率不叠乘、从众的Turn边界和真实库存检索；授权窥序／公开暗牌不等于放宽一般信息隔离。
- 用有限库存证明每Game双方PlayTrump总数≤2M；短效封锁保留Stay／反制，费用隐藏投影与私有侦知分别承接。
- 数字退回末尾、自己的旧目标可释放己方容量、对方位置不能抵扣、混合卡预检先于任何副作用；以S1已实现行为覆盖旧研究歧义。

### A.1 卡牌目录与每局限量

共 **51个定义、44组机制**（将指定2–7合并为一组、目标17／24／27合并为一组计数）。中文／英文为拟用名，产品上线须写入两份i18n字典。既有21个稳定ID不变，新增30个ID在REQ-025统一登记。原创效果是本项目设计，不宣称原版存在相同规则；旧卡来源索引保留在 [sources.md](#c-原版资料与完整引入台账)。

数量顺序为 **轻松／标准／挑战／危险／噩梦**。每个数是**每方每Game最大领取量，同时也是该方初始库存副本数**；0仅表示此配置不生成。定义不再含“最早出现难度”，五档数量是唯一生成资格依据。每个剩余实例等概率；同定义多副本自然更常见，无隐藏稀有度权重。手满不丢弃未领实例；Game内不回收、不复制、不重置已领额度。

### A.2 数学模型

难度d的初始库存总数为M，某定义有c个副本。普通获取在**当前剩余实例**中均匀取1张并移出库存：

- 每个剩余实例概率为 `1/M_remaining`；某定义下一张概率为 `c_remaining/M_remaining`。
- 首次普通Hit取得某定义的无条件概率为 `p_d × c/M`；自动开局补给没有p门控。
- 固定领取n张、没有定向检索／截流时，某定义的领取数服从超几何分布，`E[X]=n*c/M`；至少1张概率为 `1-C(M-c,n)/C(M,n)`（n≤M，c=0时为0）。
- 在h次普通Hit、手未满／库存未空／无封锁和定向事件下，额外领取B服从 `Binomial(h,p_d)`。R个Round的普通总补给机会是 `2+R+B`，首Round包含Game初始2与Round初始1。
- 卡c在固定R/h下的遭遇概率须对B混合：`Σ_b Binom(h,b;p_d) * [1-C(M-c,min(M,2+R+b))/C(M,min(M,2+R+b))]`。有手满、封锁、定向事件时改用状态模拟，不能套用未截断期望。
- 定向检索（从众）与定向移除（截流）是卡面明示的干预，不纳入“普通抽取等概率”的承诺；从众只搬运己方真实剩余副本，绝不创造第二张清场。

数量不同和“各定义概率完全相等”不能同时成立。本方案按每个实体等概率解释用户裁定，数量较多的收回自然更常见。递增的是**任意道具的获取门控概率**，不是每种卡的占比都必然递增；新增候选会稀释某些定义占比。S3保留p单调约束，在相同补给机会下比较实际获取，不能用更长BO-N冒充概率提高。

### A.3 资源与积分裁定

每方独立有限库存，开Game领取2张；每Round按先手→后手发初始数字牌后各领取1张；普通Hit结束前进行一次p门控。指定／强制／最佳抽牌、交换、退牌、调度不触发门控；重担一次Hit抽两张也只有一次门控。每张领取从己方剩余库存等概率抽取。效果补给与从众不占用Hit，也不结束当前Turn。

持牌8、桌面5；满手的普通补给与定向检索均不领取，保留库存，不延迟补领；耗尽领取0。即效、成本弃牌、留场离场进入弃置，Game内不可回收。Round清理全部留场与绑定／暗牌倍率／侦知标记／待触发，保留手牌及库存；Game清空重建，Match结束停止发放。每次PlayTrump消费一个真实未用实例，所有补给只移动库存，故每Game双方PlayTrump总数≤2M，无无限用卡循环。

一般赢家得分为 `1+min(2,max(0,a-d))`，输家0；平局双方0。a汇总赢家施压、战备施压、背水满足条件时的+2、押注对应方向；d汇总输家缓冲。息战有效时额外分归零；输家护身有效时最终得分0（显式的基础分豁免）。正常有胜者得1–3分；护身可制造0分回合，有限单副本与可拆解性防止无限防御。仅在结算一次性加分，不在出卡时颁分。

顺序：到达安静停牌条件→揭牌→结算专属数字修正（共生）→四象限判胜→积分修正／护身→加分→目标递延→局／场胜→清理。3:4加2为5:4直接胜局；3:4加1为4:4后目标7；6:6、目标9加3为9:6胜局。护身0分仍完成Round并轮换先手。双方积分不会在同一Round同时增长。

### A.4 共生、双效暗牌与从众

原始暗牌h是1–11唯一实体，任何道具不重写其ID。用m∈{1,2}记录本Round有效倍率，明牌修正独立。没有共生时有效总和为明牌贡献和+m*h。共生仅在揭牌后的结算阶段，把两方暗牌贡献都设为 `m_A*h_A+m_B*h_B`，同时计算、不逐方递归；不提前将对方h写入自己的观察。

例：A暗3明10，B暗8明5；平时13:13。共生结算变为21:16。A先对B用双效暗牌，立即成为A13、B21（B知道自己的8，A仍不知道）；再共生结算为29:24，双方爆牌、B获胜。两张共生全局替换而非重复加；双效暗牌不能把2倍再叠成4倍，归一把自身倍率恢复1。目标变化后按最终目标比较，可能改变“挽救／加害”的方向。

从众观察的是**对方下一次Turn**，不是下一个Round或Game。它在对方该Turn第一张合法PlayTrump消费时记录公开定义（合法消费后效果失败也算），Hit／Stay、领取与费用弃牌不算出卡。对方此Turn没用卡则从众到期失效；有记录则在自己下个Turn开始前检索自己剩余库存，同定义存在且手未满才移入手牌。成功／缺牌／满手处理后离场，不重放被记录卡的效果、不换人。若Round先结束则随清理失效；被拆解也不保留待办。对方可先出低价值卡误导，自己本局已领过唯一清场则无法再领清场。

### A.5 终止、容量、信息与随机

- 所有留场先基于公开条件、费用和替换后的己方占位进行容量预检，之后才消费、支付、执行onPlay、安装table、处理既有触发器。自己的旧目标可腾己方一格，对方旧目标不能抵扣。无条件放置后不会因隐藏牌面二次拒绝；本批没有“看隐藏值决定放置成功”的卡。
- 双效暗牌、识破、共生明确扩展S1数字效果能力；退换仍只作用于明牌，不涉及暗牌实体移动。识破／明志后该逻辑暗牌槽位仍受倍率／共生影响；隐藏状态由公开事件决定，不再永远固定为“索引0必隐藏”。
- 窥序得到的是**依法授权给使用者的局部信息**，不是AI读取真实牌堆的后门。最多两张私有片段须连同接收者投影；任何堆修改使位置标记过期。对手只见“用过窥序”，不知道其数值；识破后的暗牌合法公开。016／020的默认隐藏回归继续保留。
- 整备／破釜的费用弃置身份不对对手公开；公开道具消费仍设置usedTrump并重置quietStays，费用不是第二次PlayTrump，不触发余粮／从众。弃置数据必须区分公开使用与隐藏费用，不能把全部discarded数组直接投给对方。
- 封锁只作用于下一个明确Turn，始终允许Stay与反制，不影响当前使用者的行动权；压制不能指向另一张压制，避免活动状态相互依赖环。移花仅交换表中允许转移卡，不交换全局／绑定／封锁实例。
- 既有余粮按放置序响应每次其他PlayTrump至多一次，安装本卡不自触发，领取／弃置／控制权交换不触发；最多2次且耗尽离场。新待办先登记，在目标Turn边界执行；取消动画不取消已提交效果，退出／重开取消整场待办。
- 真实数字洗牌流、道具Hit门控流、道具实例选取流、AI搜索流分别注入；搜索不能拿到前三者。合法普通Hit完成数字抽取后门控流消耗1次，即便手满／库存空；成功但不能领取时不消耗选取流。普通领取每张消耗选取流1次（含仅余1张），满手／空库存0次；定向检索／移除0次，重复定义按最早原始实例序选定。全部非法命令0次；初始化先校验后随机。
- 数字牌保持S1洗牌后顺序抽，退牌追加末尾；效果修改堆序只在卡面明示时进行，不额外洗牌。被绑定明牌离开手牌回堆，其绑定修正离场；易位则绑定随数字实体移动、控制方不变。

### B.2 权威数字与观察

数字实体仍为1–11各一张，其原值永不被道具重写。有效贡献是派生结果：原值、暗牌槽位倍率、绑定明牌修正、结算专属修正。倍率最大2，明牌减值最低1；两种明牌修正可以同时存在，按原值+所有增值−所有减值后统一max(1,·)，不按安装顺序截断。绑定修正的实例唯一，不复制数字牌。

- 默认首张是逻辑暗牌槽位，但揭示与否由显式公开状态决定；明志／识破可提前揭示，自己始终知道自己的原值。
- 观察只包含依法已知的原值及可计算贡献。未揭示对方的总和仍为null，公开倍率不能变成公开实际增量；共生未结算时只有待结算效果标记。
- 窥序的私有片段仅投影给使用者，最多2张，附数字堆变更序号；堆修改时位置标记过期。即使标记过期，策略可以保留合法历史并自行推断，但观察不继续声称旧位置仍真实。
- 公开事件与每帧快照使用同一投影；隐藏费用弃置、库存顺序、对方私有片段不混入公开discarded或日志。识破后依法已公开的数字不再强行隐藏。
- 暗牌变换只作用于贡献，退牌／交换仍不能移动逻辑暗牌实体；换目标后重新派生，不保存不可逆busted标志。

### B.3 命令、触发与原子顺序

PlayTrump包含实例、按定义需要的公开目标和自己费用实例；不能由UI决定赢家、得分或隐藏条件。顺序为：

1. 只按公开条件／自身资源检查行动方、目标、费用、替换后的己方容量。
2. 原子消费本卡并支付费用，设置usedTrump、quietStays=0。
3. 依定义执行onPlay，安装持续部分；所有帧实例守恒。
4. 对本次消费前已存在且仍有效的触发器，按放置序响应。余粮自己不触发，领牌／费用／离场／控制权交换不触发。
5. 返回完整权威终态与有序事件；保持行动方。Hit／Stay才结束Turn。

所有本批放置在公开预检通过后均成功安装；补给或指定抽取可合法失败，不能因此反悔成本或让隐藏状态影响可用按钮。若以后加入隐藏条件放置，须重新登记而非悄悄复用。

Turn边界先处理到期的封锁／压制，再处理新Turn所属方从众等自动领取，最后开放合法行动。定义用确切的player+Turn序号绑定“下个Turn”，不以计时器或动画猜测；Round结束先清理，已终局时不执行下一Turn待办。被拆解实例的触发／待办随即移除。

压制不能指向另一张压制；全局目标被压制时暂用基准21，压制离场后当前未离场目标重新生效，不恢复任何被替换的旧目标。定锚只阻止新目标安装，不阻止清除；清除后基准恢复，后续安装仍需先解除定锚。

#### 可复现实验

在仓库根目录，将下列Python代码执行，或提取本需求唯一python代码块运行。Python 3.15.0验证，种子20261021；其他Python版本采样实现差异可能改变最后几位，精确概率和接受标准不变。脚本SHA256：`beb46c23a6c52b4e2588ed7d2d9437d17635dfbcbf731b452f1af2cbfec56b8e`。它只读取本归档的附录A卡表、不访问浏览器／存储／真实引擎随机。

```python
# @req REQ-2026-021: isolated supply/settlement experiment, no game AI.
import itertools, json, math, platform, random, statistics
from collections import Counter
from pathlib import Path
CARDS = []
for line in Path("docs/requirements/archive/REQ-2026-021-contest-trump-rule-contract.md").read_text().splitlines():
    cells = [x.strip() for x in line.strip().strip("|").split("|")]
    if len(cells) == 7 and cells[0].startswith(chr(96)):
        CARDS.append((cells[0].strip(chr(96)), list(map(int, cells[3].split("/")))))
assert len(CARDS) == 51 and len({x[0] for x in CARDS}) == 51
SEED, SAMPLES = 20261021, 100000
P = [0.20, 0.30, 0.40, 0.50, 0.60]
# Predeclared acceptance: per-type MC vs exact <= 6 binomial SE + 1/n;
# instance first-draw frequency within 6 SE + 1/n; no quota violation;
# unsaturated gate rate within 6 SE, strictly increasing mean grants.
out = {"seed":SEED, "samples":SAMPLES, "python":platform.python_version(),
       "uniform":[], "flow":[], "encounters":{}, "stress":[]}
for d, p in enumerate(P):
    pool = [k for k, (_, cs) in enumerate(CARDS) for _ in range(cs[d])]
    M, n = len(pool), 10
    rng = random.Random(SEED + 1000*d)
    seen, first = Counter(), Counter()
    for _ in range(SAMPLES):
        selection = rng.sample(range(M), n)
        first[selection[0]] += 1
        for k in set(pool[j] for j in selection): seen[k] += 1
    worst = 0.0
    for k, (name, cs) in enumerate(CARDS):
        c = cs[d]
        exact = 0.0 if c == 0 else 1-math.comb(M-c,n)/math.comb(M,n)
        empirical = seen[k]/SAMPLES
        se = math.sqrt(exact*(1-exact)/SAMPLES)
        assert abs(empirical-exact) <= 6*se + 1/SAMPLES
        worst = max(worst, abs(empirical-exact))
        out["encounters"].setdefault(name, []).append({
            "copy":c, "first":c/M, "any10":exact, "mc10":empirical})
    for j in range(M):
        se = math.sqrt((1/M)*(1-1/M)/SAMPLES)
        assert abs(first[j]/SAMPLES-1/M) <= 6*se + 1/SAMPLES
    out["uniform"].append({"M":M, "max_type_error_pp":100*worst})
    # Same uniforms across levels to isolate gate monotonicity.
    gate = random.Random(SEED+7)
    extra = [sum(gate.random()<p for _ in range(12)) for _ in range(SAMPLES)]
    avg = statistics.mean(extra)
    se = math.sqrt(12*p*(1-p)/SAMPLES)
    assert abs(avg-12*p) <= 6*se
    out["flow"].append({"p":p, "extra12":avg,
        "ci95":[avg-1.96*se,avg+1.96*se], "round6_total":8+avg})
    # Delivery stress is a channel probe, NOT a card-playing or win-rate policy.
    for rounds in [6,12]:
        for spend in [0,1,3]:
            r = random.Random(SEED + d*10000 + rounds*10 + spend)
            grants=[]; blocked=0; emptied=0
            for _ in range(10000):
                bag=pool.copy(); drawn=Counter()
                state=[0,0]  # hand, skipped-full
                def take():
                    if state[0]>=8: state[1]+=1; return
                    if not bag: return
                    k=r.randrange(len(bag))
                    typ=bag.pop(k); drawn[typ]+=1; state[0]+=1
                take(); take()
                for turn in range(rounds):
                    take()
                    for _ in range(2):
                        if r.random()<p: take()
                    state[0]=max(0,state[0]-spend)
                for k,num in drawn.items(): assert num<=CARDS[k][1][d]
                sweep_index=next(k for k,x in enumerate(CARDS) if x[0]=="destroy-all")
                assert drawn[sweep_index]<=1
                grants.append(sum(drawn.values())); blocked+=state[1]
                emptied += not bag
            out["stress"].append({"d":d,"rounds":rounds,"spend":spend,
                "mean":statistics.mean(grants), "p95":sorted(grants)[9499],
                "blocked_per_game":blocked/10000,"empty_rate":emptied/10000})
assert all(out["flow"][d]["extra12"]<out["flow"][d+1]["extra12"] for d in range(4))

# Forced depletion and all-channel cap boundary in the reference bag.
out["exhaustion"]=[]
for d in range(5):
    remaining=[k for k,(_,cs) in enumerate(CARDS) for _ in range(cs[d])]
    taken=Counter(remaining)
    M=len(remaining)
    remaining.clear()
    assert sum(taken.values())==M
    assert all(taken[k]<=cs[d] for k,(_,cs) in enumerate(CARDS))
    sweep=next(k for k,(name,_) in enumerate(CARDS) if name=="destroy-all")
    assert taken[sweep]<=1
    # Follow Suit searches remaining real instances; a spent one-copy card
    # cannot be created again, including when it is not yet played.
    assert not any(k==sweep for k in remaining)
    out["exhaustion"].append(M)

def winner(a,b,target=21):
    return 0 if a==b else (-1 if ((a<=target and b<=target and a>b) or
        (a<=target<b) or (a>target and b>target and a<b)) else 1)
flips=Counter(); wins=Counter(); total=0
for ah,af,bh,bf in itertools.permutations(range(1,12),4):
    a,b=ah+af,bh+bf; base=winner(a,b); total+=1
    scenarios={"base":(a,b), "double_enemy":(a,b+bh),
               "symbiosis":(a+bh,b+ah),
               "double_then_symbiosis":(a+2*bh,b+bh+ah)}
    for name,(x,y) in scenarios.items():
        w=winner(x,y); flips[name]+=w!=base; wins[name]+=w==-1
out["opening_math"]={"states":total,"flip_rate":{k:v/total for k,v in flips.items()},
    "actor_win_rate":{k:v/total for k,v in wins.items()}}
print(json.dumps(out,ensure_ascii=False,indent=2))
```
