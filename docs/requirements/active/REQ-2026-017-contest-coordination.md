## 背景

在正式 AI 开发前先让引擎能被界面协调，处理动画、输入锁、退出取消与简单对手轮转。策略实现可替换，但不能影响权威状态提交或随机发牌。

## 方案要点

- useContest 协调命令、不可变 Match 状态、投影事件及 UI 可观察状态；先提交全部权威结果，再播放动画。播放完成只解锁，不计算积分，不凭动画决定下一行动方。
- 提供窄策略端口，只输入观察视图及合法 Hit/Stay，不传完整状态或实际随机源。占位规则确定为：自己数字总和低于 17 且 Hit 合法时 Hit，否则 Stay；只在自己的 Turn 发一个结束 Turn 的命令。
- 该占位规则借鉴经典式要牌／停牌，不复用经典 52 张牌、A 点数或庄家循环。不会 PlayTrump，不计算胜率、不搜索、无需抽取策略随机；目标变更后的策略表现不属于占位阶段优化范围。
- 用卡后仍是同一方时不能自动切换；对手停牌后再获行动权时重新调用策略，不使用永久 stood。AI 延迟任务绑定 Match/Turn 或取消代次，过期回调不得作用于新比赛。
- 提供开始、退出、重开及可观察结果接口；取消动画与策略任务后退出，刷新不恢复竞赛。共享设置经现有 API 使用，不覆盖经典存档，不迁移设置信封。
- 只提取确有两模式消费者的调度工具；先保持经典 useGame 时序，再验证最小共享改动。公开应用 API 不包含隐藏牌与库存身份。

## 验收标准

- [ ] 应用层可用固定输入完成无道具 BO5；权威结果在动画前已确定，动画跳过／取消不改变积分。
- [ ] 占位对手覆盖 16→Hit、17/21/爆牌→Stay、不可 Hit→Stay；任何情况下不主动使用道具。
- [ ] 不在玩家 Turn 或 Match 终态触发 AI；退出／重开后旧任务失效；快速连点不会重复提交或结算。
- [ ] 暂停结束后按权威行动方恢复决策，为多卡同 Turn 保留正确输入锁边界。
- [ ] 不创建竞赛对局存档、不覆盖经典保存与设置；观察接口不泄密，经典全量回归通过。
