# REQ-2026-024: S2 积分道具、补给与有限触发联动

状态: active
来源: 用户（2026-10-21：从 S2 提炼 active 需求，最终落地道具机制与 AI 对抗）
关联设计: [竞赛规则](../../design/contest-rules.md) · [ADR-004](../../adr/ADR-004-contest-turns-and-shared-boundaries.md) · [S2 排期](../../roadmap.md#s2-需求拆分与实施顺序2026-10-21)
影响模块: src/domain/contest/engine/、trumps/、积分／资源／投影测试
前置依赖: REQ-021–023；最终卡池准入在 REQ-025。
非目标: 不承诺原版全卡复刻；不以玩家出牌次数上限终止连锁；未准入封锁、费用和触发效果不预建。

## 背景

只有数字效果不足以形成道具对抗。S2 还需让进攻、防御与补给产生可解释的积分和资源取舍，并验证连续使用资源卡能终止。本项实现规则定稿后的积分修正和混合卡，为末项 AI 的组合评价提供真实语义。

## 方案要点

- 实现 pressure、shield、pressure-supply 的定稿效果。混合卡先通过容量／成本校验，再依定义执行补给与留场；库存耗尽、持牌满时部分效果是否继续由 REQ-021 明确，不整条随意回滚。
- 结算依次为最终牌面判胜→仍有效积分修正→一次加分→目标递延／Game 与 Match 胜负→清理。展示基础分、加减项与最终增量所需的公开事件；UI 不重算公式。
- shared-supply、resource-swap、harvest已由REQ-021设计纳入，须落实双方补给顺序、额外弃牌选择与不足拒绝、有限次数触发与耗尽离场，并与新增从众／补给卡一起验证。
- 触发以定义的顺序处理，区分使用卡、支付费用、领取资源和离场；先前／新装的触发器是否响应当次消费必须明确。每条链给出由有限触发次数、非递归队列或其他明确资源约束产生的每命令终止依据；不能用搜索深度或隐藏单 Turn 上限截断合法行动。
- 不创造瞬间Match胜利或旁路安静停牌的得分动作；赌命仅在Round正式结算后覆盖Game胜负；不因资源耗尽阻止 Stay 和后续正常比赛。

### S1 信息边界承接

承接 [roadmap 复查清单](../../roadmap.md#s2s3-承接的-s1-外审复查项2026-10-21) 的隐蔽消费观察。若采用 resource-swap 的暗置费用或其他隐蔽消费，重新评估 usedTrump、手牌／销毁审计数量、事件载荷、逐帧观察、合法目标与未来 AI 历史；公开“使用了本卡”不等于公开被弃成本的身份。不同隐藏弃牌身份但相同公开动作的观察须等价。没有此类卡时逐项记录不适用，不扩展隐藏玩法。

### REQ-021 定稿输入（2026-10-21）

本项负责[51卡表](../archive/REQ-2026-021-contest-trump-rule-contract.md#a-51卡规则限量与概率)标为REQ-024的全部定义，包含从众、短效静默／断供／定锚／压制、有限余粮、隐蔽费用、补给及护身0分特例。一般分数1+min(2,max(0,a-d))，息战清额外分，输家护身使最终得分0；平局仍0，不同时给双方加分。

从众只观察对方下一Turn第一张合法消费、自己下Turn起始检索真实库存，不算Hit、不生成副本；Round提前结束或拆解取消待办。短效封锁精确绑定Turn，保持Stay／反制；压制不可指向压制以免形成依赖环。整备／破釜费用身份只给自己、数量公开，费用不是出卡，不触发余粮／从众；因此S1隐蔽消费复查在本批明确适用，须完成而不能标不适用。每命令触发次数有限、领取不递归触发；引入生成后不得沿用每Game双方PlayTrump≤2M作为全局证明。

### 2026-10-21 新增局胜与技能接缝

承接[022](../archive/REQ-2026-022-contest-trump-resources.md)的赌命sudden-death：当前Round决胜者直接赢Game，平局保留标记、0分护身不挡局胜；不提前结算、不直接赢Match、标记不重复叠加，Game清理移除。与悔牌、平局、正常积分／递延及末局场胜一起验证，颁发Game／Match结果仅一次。

回仙skill-revival的定义／场次数恢复和本Game额外许可语义在022确定；本项提供明确技能效果接缝，**完整执行与可用性／生产准入留027主动技实现**，没有选定技能的S2过渡阶段不能发放回仙。不是另设自动复活、解除封锁或恢复待办。

费用删除不算PlayTrump、领取或生成；原卡已销毁仍可触发其消费事件，不能将销毁审计当新资源。生成、转入不消耗自己的库存额度；有生成后的终止依据是每命令有限触发及Turn-start幂等，不设每局出牌总上限。隐蔽费用复查在本项已适用，027再扩展隐身技能／次数投影，不得以未适用跳过。

### REQ-023 已交付接口承接

[REQ-023](../archive/REQ-2026-023-contest-trump-effects.md)已实现29个数字／留场及悔牌定义。复用contributions／effectOperations与唯一结算流程，不另建数字效果或比较器；移花保留记录来源、控制方、顺序和剩余次数，本项须以真实计分／补给触发验证转移后的执行。

新增计分、封锁、触发次数及库存变更应记录实际EffectDelta，并扩展undo的穷尽处理；悔牌不回滚整场快照、不返还已打卡／费用或真实随机。删除库存副本的卡须明确对应逆操作与新实例来源，不能将既有“手牌删除”的逆操作直接用于恢复旧库存。补充悔牌与新触发／赌命的交叉证据；本段为本项待办，不将023夹具中的元数据当成完整计分实现。

### 2026-10-22 外审承接：悔牌恢复手牌的容量

021–023外审指出：undo.ts逆转trump-deleted时会重新生成被删除道具，手满则抛RangeError，而当前legalTrumpCommands未预检此分支。023实际29定义下，该差量只来自悔牌逆转补给，下一张悔牌消费自身后有可用位置；本项引入shared-supply／pressure-supply／harvest等双方或连续补给后，必须重新验证可达性。

增加补给→悔牌→再悔牌、双方受益、手满／差一格及触发领取的真实命令用例，逐步核对逆操作顺序和容量。若扩展后容量可以阻塞撤销，先明确符合观察边界的前置拒绝或其他定稿处理，使legalActions与transition一致；合法可提交命令不能在消费后因容量抛错，不可静默丢牌、恢复原卡体或回退库存／随机。结论、处理及确定性证据回填本项。

## 验收标准

- [ ] 无修正、仅进攻、仅防御、双方进攻、抵消后封顶、平局／双爆平局、上下限与定稿0分边界均有确定性断言。
- [ ] 3:4 加2直接胜局，3:4 加1变4:4并递延，6:6在当前目标下的跳分与末局场胜均只结算一次；不能先清理积分卡再算分。
- [ ] 真实混合卡覆盖满桌拒绝无副作用、补给部分失败但留场的定稿结果、清除持续效果而不回滚补给。
- [ ] 所有准入补给／触发／费用卡覆盖链顺序、次数、耗尽、清理和多卡联动；给出最长链或可证明有限上界，非法指令不推进资源。
- [ ] 隐蔽消费提供等价观察、事件与实例守恒证据或明确不适用理由；公开弃置不混入隐藏成本身份。
- [ ] 外审承接的补给→悔牌→再悔牌及满手边界通过，双方恢复容量与触发顺序明确；合法命令不因逆操作容量抛错，非法拒绝仍零副作用且不泄露隐藏身份。
- [ ] 任务收尾测试／类型／格式、domain 纯度通过，回写规则与 roadmap 对应复查证据。
