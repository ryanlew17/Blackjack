# REQ-2026-028: S2 末项：道具与主动技组合 AI 对抗

状态: active
来源: 用户（2026-10-21：S2组合AI；主动技插入前置，原REQ-027顺延）
关联设计: [竞赛规则](../../design/contest-rules.md) · [ADR-004](../../adr/ADR-004-contest-turns-and-shared-boundaries.md) · [S2 排期](../../roadmap.md#s2-需求拆分与实施顺序2026-10-21)
影响模块: src/domain/contest/ai/、必要的engine纯函数、src/application/contest/ 及同目录测试
前置依赖: REQ-021–027 全部验收；本项必须为S2最后实施项。
非目标: 不透视、不改真实抽牌、不用不同难度的策略／预算，不承诺全局最优或原版AI复刻；五档平衡与解锁仍在S3。

## 背景

S1 baselinePolicy只按17阈值Hit/Stay，不会多卡组合或主动技。54卡与15技能的真实规则、战前选择及反应窗口就绪后，本项实现受观察边界约束的信息推断、动态评价与有限搜索，最终交付可完整对抗的标准BO5。

## 1. 输入、推断与行动

- 策略只接自身观察、公开规则、合法动作／目标和已授权的事件记忆；不能接真实MatchState、未知暗牌／手牌、真实库存／牌堆顺序或真实随机函数。窥序、灵闻仅授予发动方的暗牌值、公共提前揭示、双生花获得的身份属于明确授权，不能因此取得其余隐藏真值。
- 每Round初始数字为1–11各一张，但之后可生成同值新实例、删除或转移。根据公开来源和已知信息维护可能状态／采样分布，不再凭“唯一数字缺失”推断生成模型中必然的暗牌；未知分支始终是推测。私有推断不得输出到玩家界面。
- 模拟状态由观察构造，复用权威效果语义或经过对照测试的纯模拟接口；不复制第二套结算器。剩余库存、生成与转入分开建模，不把初始副本数当作所有获得渠道的总上限。
- 动态生成PlayTrump及目标／费用、ActivateSkill、反应发动／放行、Hit、Stay。所有合法候选只根据允许信息，不能预筛强运是否找得到、替罪隐牌真总分、对方是否隐身发动。
- 相同观察、授权历史和搜索种子必须得到相同选择，与后台隐藏真值无关；隐身技能未公开的布置／次数是信念分支，不是确定事实。

## 2. 组合评价、搜索与预算

- 搜索“道具→主动技→道具→Hit/Stay”、对手合法回应、反应窗口及不确定抽牌；衡量预期回合积分、局／场赛点、反制风险、跨Round资源和跨Game场次数。可少出牌、保留技能或直接Stay，不以静态priority决定最终动作。
- 回仙可恢复次数并额外开启本Game一次技能，赌命可能使Round胜负直接决定Game；评价必须使用真实局胜语义。破万法的两Round禁补给／技能、生生不息长期生成、魂迁隐身重定向及双生花反应时机均进入可见状态下的对抗预测。
- AI战前从可用技能中均匀纯随机选取一次（由REQ-027先实现），不参与搜索，不针对玩家技能重抽。**发动策略**则在合法信息和有限预算内最大化对抗收益；不以随机点技能替代动态评价，也不承诺全知最优。
- 实施时先登记统一节点／深度／采样预算、评价权重、近似等价容差与基准场景，再运行评估。五档共用策略与预算，S3只基于证据统一调整；难度差异来自赛制／资源／技能次数。
- 搜索采样与近似等价打破平局使用独立种子源；不能推进技能选择、真实技能效果、数字洗牌、Hit门控或库存选取的随机流。保持相同实际命令序列时，改变搜索预算／候选顺序／调用次数不改变后续真实结果。
- 每次只提交一个普通动作或一个反应，提交／回放后重新观察。夺心魄由引擎完成一个受控Turn，不把模拟中的未来Hit计划逐条越权提交。预算限制计算，不限制玩家合法用卡数量，耗尽时返回当前观察下的合法启发式动作。
- 先实测同步搜索，实测有需要才分片或使用其他调度。记录环境上单次决策计算目标P95≤100ms、最大≤250ms（不含动画／思考等待）；分片时最长主线程片段≤50ms。超限调整统一预算并重测，不能跳过性能证据。

## 3. 调度与终止性

暂停、退出、重开、不可见／恢复、反应窗口失效和回放取消均使待执行决策失效。恢复只根据当前权威状态的AI投影计算，不续跑旧计划。自己的PlayTrump或主动技后仍可继续决策；反应不得越过已提交命令。

每命令触发队列必须可终止，有限次数触发不递归自激，Turn-start生成幂等；不能沿用有生成前“每Game最多2M次出卡”的证明。搜索计划有限且最终给出可执行动作，不在合法用卡后无限重新选择同一条失效计划；不新增玩家每Turn出牌上限、极端抽尽补牌或对局时长硬截止。

## 4. S2证据汇总与后续

本需求记录S2各项交付、54卡／15技能证据、完整比赛、真实浏览器边界及S3待平衡项；不新增长期handoff。首批15技能与S2卡池不是原版全卡扩充的替代；原版非剧情项继续按roadmap在S4结束前闭环。

REQ-021的51卡供应模型和开局枚举保留原始参数与结论；REQ-022新增三卡与生成、REQ-027技能模型需实际对抗评估。不能声称旧500,000样本验证了新模型、全局最优或五档人类胜率。资源耗尽自然按0领取处理并保留正常动作，不把它另立为需要特殊兜底的玩法项目。

## 验收标准

- [ ] 策略接口／依赖守卫禁止真实状态与真实随机；隐藏数字／手牌／牌堆／隐身待办和实际技能次数成对变化而授权观察相同时，动作一致。
- [ ] 确定性用例覆盖多卡组合优于单卡、爆牌挽救、目标变更、共生／倍率反例、攻防赛点、保留清场／场技能次数、从众诱导、指定抽取未知成功与对手反制；断言合理动作集合，不只检查合法。
- [ ] 覆盖主动技与道具先后顺序、回仙再发动、赌命局胜、破万法对公开／隐身／生生不息、双生花反应放行／发动、魂迁重定向及生成后的数字推断；无可用技能仍有合法行动。
- [ ] 技能选择均匀随机且不随搜索变化；相同观察／种子可重现，搜索与真实各随机流隔离。固定实际命令序列下后续数字、道具和技能结果一致。
- [ ] 预算耗尽、无道具、空数字堆、手满或自然无可领取资源均能推进；每命令有限触发、同Turn多卡／技能后Hit或Stay只交权一次，不以隐藏出牌上限解决空转。
- [ ] 思考中、用卡后、技能反应中、通知内暂停、重开退出及强制旧结果投递均不提交陈旧命令、不重复消费；恢复仅有当前有效决策。
- [ ] 固定至少20个记录种子的完整标准BO5（双方初始先手均覆盖，技能按真实均匀选择）验证无卡死／泄漏；补充高档专用卡／技能的固定引擎场景。对照基线记录胜率、分差、回合数、时长、平均／最长用卡链、技能选择／发动／保留和生成数量；若样本遇到空库存如实记录，不据小样本声称五档已平衡。
- [ ] 固定场景记录节点数、截断／回退次数、决策耗时P50/P95/最大值及机器环境，达到性能目标，结果写回统一预算。
- [ ] 针对性浏览器确认AI实际用卡／组合／主动技及玩家反应、暂停恢复、终局，中英窄视口反馈；任务收尾测试／类型／格式及domain纯度通过。S2证据归入本需求，S3参数与长期卡／技能扩充待办回写现有roadmap。
