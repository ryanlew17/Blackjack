# Blackjack — The Green Room

[English](./README.md) | **简体中文**

一款本地优先的单人 Web Blackjack 游戏。在经典绿色绒面牌桌上迎战庄家，或进入**竞赛模式**——受《生化危机7》21 点启发的共享数字牌对弈。一切均在本地运行：无账号、无遥测、无后端。基于 React、TypeScript 与 Vite 构建。

## 功能特性

- **双模式入口**：经典恢复原有牌桌进度；竞赛新开标准五局三胜对决，交替行动、回合积分、递延胜局目标，对手为确定性 AI。
- **完整经典规则**：要牌、停牌、加倍、分牌、保险、晚投降、撤销或清空下注、全押。
- **动作提示**：可分牌、加倍或投降时，动作按钮下方显示一行说明——触屏可达，桌面悬浮提示保留。
- **响应式 2D 牌桌**：自有 SVG 纸牌与筹码、流畅动画、键盘操作和减少动态效果支持。
- **双语界面**：英文与简体中文，自动识别浏览器语言并保存手动选择。
- **可选音效**：合成发牌和筹码声音，支持音量调节与静音。
- **经典续局**：刷新进入首页，再进入经典时恢复当前决策点或已完成的结算结果，动画中刷新也能恢复。竞赛仅存在于内存，离开或刷新即放弃。
- **便携存档**：导出 JSON 备份，在其他设备导入；先校验，再确认替换。
- **本地保护**：跨标签页修改时暂停操作；浏览器存储不可用时继续游戏并提示导出。
- **关于项目**：设置 → 关于，查看当前版本、项目仓库、MIT 许可及 GitHub Issues 反馈入口。

## 立即开始

下载最新的 Release 构建包，解压后双击 `index.html` 即可——无需 Node.js 或本地服务器。单文件构建可在 Chrome、Edge、Firefox、Safari 中经 `file://` 运行；同一目录也可上传到任意静态 HTTP/HTTPS 服务器的根目录或子目录。项目没有 Service Worker：通过网站方式游玩时需要服务器可访问。

## 牌桌规则（经典模式）

- 初始资金为 **2,000 虚拟筹码**，每局重新洗一副 52 张牌。
- 人头牌为 10 点，A 可作 1 点或 11 点；电脑固定为庄家。
- 开局检查天然 Blackjack；庄家明牌 A 时先完成保险选择。双方天然则平局。
- 天然 Blackjack **净赔 3:2**，普通获胜**净赔 1:1**，平局返还下注。
- 普通 21 点自动结束玩家行动，但不保证获胜。庄家所有 17 点均停牌，包括软 17。
- 仅初始两张牌且余额足够时可加倍：追加同额下注，补一张牌后停牌。
- 初始同点值牌可分为最多两手，不可再分。分 A 各补一张后停牌且不可加倍；其他分牌可加倍，分牌 21 点不算天然。
- 庄家明牌 A 时先选择保险再检查天然：保费为原注一半，天然时保险净赔 2:1，主注独立结算。
- 排除庄家天然后，未分牌且未要牌/加倍的初始手可晚投降，返还主注一半；保险损失不退还。
- 以整筹码下注，余额可含半筹码；全押保留无法下注的半筹码。

## 竞赛模式

受《生化危机7》21 点启发的对决变体。每回合从一副共享牌堆发牌，数字 1–11 各一张；双方各起手两张、首张暗牌，轮流要牌或停牌，两次连续停牌后揭晓双方手牌。比赛为五局三胜制：先得 5 分者胜，4:4、6:6 平分时递延目标。当前可玩标准无道具比赛——道具卡、难度选择、图鉴与组合搜索 AI 仍在路线图中。完整规则见 [contest-rules.md](./docs/design/contest-rules.md)。

## 存档与隐私

经典进度与共享偏好仅保存在当前浏览器，任何数据都不会离开本机。可导出 `.blackjack.json` 备份并在其他设备导入——文件先校验，再确认替换。过旧（v1）或损坏的存档会被拒绝而非猜测处理：请导入有效备份或明确重新开始。清理站点数据会删除自动存档。竞赛比赛不存档。存档是未加密、可编辑的单机数据，不提供防作弊能力。项目不包含账号、遥测、广告或后端。

## 从源码运行

需要 **Node.js 24.x ≥24.22.1 或 26.x ≥26.12.1** 和 npm。

```bash
npm ci
npm run dev        # http://127.0.0.1:5173
```

- **Windows** —— 双击 `start-game.bat`。
- **macOS** —— 双击 `start-game.command`（首次若被 Gatekeeper 拦截：右键 → 打开，或在终端执行 `bash start-game.command`）。
- **Linux** —— 终端执行 `bash start-game.command`（或先赋予可执行权限，再在文件管理器中双击“在终端中运行”）。

启动脚本会检查 Node.js 环境，首次运行自动安装依赖，随后启动开发服务器并自动打开浏览器。执行 `npm run build` 可生成可分发的单文件 `dist/`；`npm test`、`npm run typecheck`、`npm run format` 为质量检查命令。贡献前请阅读 [AGENTS.md](./AGENTS.md)，调整行为或启动命令时请同步更新中英文说明。
